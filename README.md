## About

I build Minecraft clients, local control panels, and automation workers.

Most of the work is **Go** and **Java**. Panels are plain **HTML/CSS**. Scripts in **Python** and **C#** when that fits.

## What I do

| | |
| :--- | :--- |
| **Minecraft clients** | Headless protocol clients, session login, inventory and chat hooks |
| **Java launchers** | Isolated game dirs, HeadlessMC-style sessions, live console |
| **Automation** | Pipelines, background workers, schedulers, retry / cooldown logic |
| **Dashboards** | Local HTML/CSS panels for stock, jobs, logs, and bot control |
| **Bot services** | Private clients, account tooling, multi-session runners |
